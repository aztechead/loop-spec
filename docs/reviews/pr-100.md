## `f5bec2c` — one shell mode

Claim vs tree: every shipped `*.sh` under `lib/` and `hooks/` (not
`*.test.sh`) opens with `set -euo pipefail`, or `set -uo pipefail` plus a
same-line reason. None uses the relaxation.
The coverage suite
([`ffe20f2`](https://github.com/aztechead/loop-spec/blob/ffe20f2442fcd0d84beb615e54b5b85fbe3a4c55/tests/shell-mode-coverage.test.sh))
is registered in `tests/run-all.sh`. It now also refuses a bare `shift [2-9]`
with no `||`. 208 scripts passed here.
[`skills/shared/human-code.md`](https://github.com/aztechead/loop-spec/blob/f5bec2ce1745b4d884b645e18323e6590b550f4a/skills/shared/human-code.md)
states the rule under “fail loudly”. 208 scripts passed the new suite here.

Bugs the conversion had to fix to turn `-e` on, and that the PR body names:

- [`oneshot.sh` `footprint_shape`](https://github.com/aztechead/loop-spec/blob/f5bec2ce1745b4d884b645e18323e6590b550f4a/lib/graph/probes/oneshot.sh):
  `[[ "$p" == /* ]] && full ...` left the function’s status at 1 on every
  relative path; under `-e` the probe aborted. `return 0` is the fix.
  Relative-path oneshot cases in `tests/lib/graph-probes.test.sh` would have
  gone red without it (141 pass here). No case names this last-command trap
  by itself.
- [`prepare-environment.sh`](https://github.com/aztechead/loop-spec/blob/f5bec2ce1745b4d884b645e18323e6590b550f4a/lib/prepare-environment.sh):
  `rc=$?` after the watchdog ran after `-e` would already have exited.
  `|| rc=$?` makes exit 10 / 12 reachable. `tests/lib/prepare-environment.test.sh`
  covers “setup command failure has a distinct exit” (45 pass).
- [`deliver.sh`](https://github.com/aztechead/loop-spec/blob/f5bec2ce1745b4d884b645e18323e6590b550f4a/lib/deliver.sh)
  / [`pr-delivery.sh`](https://github.com/aztechead/loop-spec/blob/f5bec2ce1745b4d884b645e18323e6590b550f4a/lib/pr-delivery.sh):
  `jq | tail` / `ls-remote | cut` under `pipefail` aborted instead of
  treating empty as “no answer.” `|| true` keeps the fail-safe empty. The
  FastAPI `post_gate_drift` / `pushed-no-pr` cases still pass (`deliver` 152,
  `pr-delivery` 161, `checkpoint-pr` 44). The no-`gh` fixture now ships
  `dirname` so `. credential-refresh.sh` does not abort under `-e`.
- Trailing flag with no value: converted scripts `shift 2 || exit 2` instead
  of looping. At-end EXECUTE squash logs on stderr when it leaves task
  commits in place instead of failing the gate
  ([`execute-exit-gate.sh`](https://github.com/aztechead/loop-spec/blob/f5bec2ce1745b4d884b645e18323e6590b550f4a/lib/execute-exit-gate.sh)).

The sweep matches house style. It is also 73 files on a FastAPI live-run PR.
That is a review-cost fact, not a defect in the conversion.

## `ffe20f2` — every `shift N` says so

Zero remaining `shift N` lines under `lib/` and `hooks/` lack `||`. The
coverage suite greps for `shift [2-9]` at end-of-line or `;;` without `||`.
`tests/lib/feature-init.test.sh` still passes (49). `compact-gate.sh
--feature-dir` as the last argument now prints usage and exits 2.

The advertised “script’s own usage path” is not what runs when the parser
still writes `"$2"` before `shift 2`. Under `-u` that is bash’s unbound
variable, exit 1, and the new `|| usage` never fires. About 61 sites look
like that (`feature-init.sh`, `feature-bootstrap.sh`, `conflict-monitor.sh`).
Parsers that use `${2:-}` then `shift 2 || usage` (the `f5bec2c` conversions,
and `compact-gate.sh`) do print the named message. `adhoc-ledger.sh` calls
`require_value` first, so it is fine.
