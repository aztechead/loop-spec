## Oneshot policy change (`2f64699`)

The gate no longer escalates a diff file the footprint does not name, and
`generated_by_manifest` is gone. The footprint still selects the route (at most
three named files, each must appear in the diff). A file outside that list is
the reviewer’s finding: **Important** if the change authored it (blocks),
**Critical** with `route: full` when authored files outgrew the footprint,
mention-only for scaffolder output beside a manifest
([`agents/code-reviewer.md`](https://github.com/aztechead/loop-spec/blob/2f646991d0a207ba42e3ec7101eee62d5f9399f6/agents/code-reviewer.md#L39)).
The oneshot skill commits everything the change wrote.

That is a real answer to “the allowlist trails every scaffolder release.” It
also means a oneshot can ship extra authored files if the reviewer misses
them. The original FastAPI failure mode (lockfiles committed **inside
DELIVER**, named as `verifiedSha`) is still closed by `post_gate_drift` and
`dirty_worktree`. What is no longer closed is an extra file committed **before**
the gate on a still-oneshot route.

## Residual

1. Snapshot-NOTE stderr is string-pinned (`print(note, file=sys.stderr)`), not
   exercised as “first stdout line stays `NEXT`,” and the escalate NOTE is not
   in that pin. Cheap to add next to the existing phase-snapshot verify case.
2. `execute-prepare.sh` still does not auto-commit stranded artifacts in
   workspace mode, and the script is still `set -uo` without `-e` (the commit
   path is an explicit `|| exit 2`).
3. Oneshot extras are judgment. If a later live run ships a fourth authored
   file because the reviewer called it scaffold or Minor, that is this policy,
   not a missed patch.
4. [`driver.py`](https://github.com/aztechead/loop-spec/blob/2f646991d0a207ba42e3ec7101eee62d5f9399f6/lib/graph/driver.py)
   still matches `^route: *full\s*$` with no quote strip
   ([oneshot boundary](https://github.com/aztechead/loop-spec/blob/2f646991d0a207ba42e3ec7101eee62d5f9399f6/lib/graph/driver.py#L1316),
   [gate-held escalate](https://github.com/aztechead/loop-spec/blob/2f646991d0a207ba42e3ec7101eee62d5f9399f6/lib/graph/driver.py#L1348),
   [specIntentSeen](https://github.com/aztechead/loop-spec/blob/2f646991d0a207ba42e3ec7101eee62d5f9399f6/lib/graph/driver.py#L1401),
   [`spec_escalate`](https://github.com/aztechead/loop-spec/blob/2f646991d0a207ba42e3ec7101eee62d5f9399f6/lib/graph/driver.py#L2400)).
   The probe and the lint strip YAML quotes. An operator-written
   `route: "full"` can make `spec_escalate` inject a second unquoted
   `route: full` line. The live writer (`spec_escalate` itself) writes
   unquoted, so this is the lint’s sibling, not the FastAPI path.
